Security

Check that your download is genuine

Every CPE Trade Pro installer we publish has a unique SHA-256 fingerprint. Compare the fingerprint of the file on your computer with the value below — if they match, the file is exactly the one we released, unaltered and uncorrupted. If they do not match, do not install it.

🔢
What a SHA-256 checksum is A checksum is a fixed-length fingerprint calculated from every byte in a file. Change even a single character and the fingerprint changes completely. Because the value is unique to the exact file, it is a simple way to prove that what you downloaded is what we published — and that nothing (or no one) altered it on the way.

How to check on Windows

Open PowerShell (press Win, type PowerShell, press Enter), then run this with the path to your downloaded file:

Get-FileHash "C:\Users\YourName\Downloads\CPE-Trade-Pro-Setup-6.3.0.exe" -Algorithm SHA256

PowerShell prints a Hash value. Compare it, letter by letter, with the checksum above. Differences in upper or lower case do not matter.

How to check on macOS or Linux

Open Terminal and run shasum -a 256 (macOS) or sha256sum (Linux) with the path to your file:

shasum -a 256 ~/Downloads/CPE-Trade-Pro-6.3.0-arm64.dmg

The long string on the left is the file's fingerprint. It should equal the published value for that file.

If the checksum does not match

A mismatch means one of two things: the download was interrupted or damaged, or the file is not the one we published. Either way, do the following:

  1. Do not install the file. Delete it.
  2. Download it again from the links on this site or from our GitHub releases page.
  3. Re-check the new file. A complete download should now match.
  4. Still not matching? Message us on WhatsApp or email Anurasiri123@gmail.com with the filename and the hash you got, and we will confirm the current value.

If you got a download from somewhere else

We only publish installers on this site and on our GitHub releases page. If someone sent you a file directly on WhatsApp, Telegram or social media — or pointed you to another website — treat it as untrusted until its checksum matches ours.
