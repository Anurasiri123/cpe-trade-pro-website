Install notes: CPE Trade Pro builds are not store-signed, so your device shows a security warning on first launch. This is expected — open each platform's Install steps & warnings above for the exact clicks. Read the iPhone install steps.
🪟 Windows — “Windows protected your PC” warning
  1. Run the downloaded CPE-Trade-Pro-Setup-5.5.0.exe.
  2. If Windows SmartScreen appears, click More info → Run anyway. The build is simply not code-signed.
  3. Approve the User Account Control prompt (Yes) if it appears.
  4. If your antivirus quarantines the file, choose Allow / Keep, then run the installer again.
🍎 macOS — “cannot be opened because the developer cannot be verified”
  1. Open the .dmg and drag CPE Trade Pro into Applications.
  2. First launch: right-click (Control-click) the app → Open → Open again.
  3. Or go to System Settings → Privacy & Security and click Open Anyway.
🤖 Android — “unknown apps” and Play Protect warnings
  1. Download the .apk. Chrome may warn it can harm your device — tap Download anyway.
  2. Open the file. Android asks to allow installs from this source — enable Allow from this source for your browser or Files app.
  3. If Play Protect says the app is unsafe, tap More details → Install anyway.
  4. Tap Install → Open.
📱 iPhone / iOS — unsigned IPA signing
  1. Install Sideloadly on a Windows PC or Mac.
  2. Connect your iPhone by USB and tap Trust on the phone.
  3. Drag the .ipa into Sideloadly, enter your Apple ID and click Start.
  4. On the iPhone: Settings → General → VPN & Device Management → trust the developer profile.
  5. A free Apple ID signature expires after 7 days — re-sign to keep using it.
